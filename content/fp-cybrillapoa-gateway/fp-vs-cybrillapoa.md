#### Cybrilla POA
Cybrilla POA acts as a digital branch of AMCs by acting as the official point of acceptance of orders. It is able to provide the following benefits to distributors:
- Zero cost (no PG cost, no KYC cost, no operations cost)
- Single agreement to access multiple AMCs.
- Order acceptance via ONDC protocol

*You can find more information on POA and its value proposition [here](https://poa.cybrilla.com/)*

#### Fintech Primitives (FP)
	
FP acts as a technical service provider (TSP) that simplifies the entire integration with Cybrilla POA so that distributors can go live fast.
- FP is essentially a SaaS platform
- It integrates with OPAT in the backend and provides a simplified MF domain native interface so that GTM is fast
- It provides additional value added services like reporting, console, etc.
