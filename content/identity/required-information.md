## Required information about the investor
#### All the data points needed for a kyc application

### Data points

The following information about the investor needs to be collected for a successful kyc submission
1. Full name of the investor ( `name` )
2. PAN number of the investor ( `pan` )
3. Last 4 digits of the Aadhaar number ( `aadhaar_number` )
4. Father name in full ( `father_name` )
5. Gender ( `gender` )
6. Date of birth ( `date_of_birth` )
7. Marital status ( `marital_status` )
8. Residential status ( currently we only support indian resident individual ) ( `residential_status` )
9. Occupation ( `occupation_type` )
10. Countries of Citizenship ( `citizenship_countries` )
11. Country of Nationality ( `nationality_country` )
12. Country of birth ( `country_of_birth` )
13. Place of birth ( `place_of_birth` )
14. Income slab ( `income_slab` )
15. Political Exposure details ( `pep_details` )
16. Declaration of Non Indian Tax Residency ( `tax_residency_other_than_india` )
17. Email ID and mobile number of the investor ( `email`, `mobile` )
18. Photo copy of investor's Signature ( `signature` )
19. Proof of Identity ( `identity_proof` )
20. Proof of Address ( `address` )
21. Geo location ( `geolocation` )
22. Electronic signature on the application form
